开发调试环境搭建

May 16, 2026 · 2 min

开发调试环境搭建#

首先，个人的学习方式是内核不动，改dts，然后编译成dtb，uboot加载dtb，启动linux，驱动程序通过insmod验证。

现阶段主要是devicetree还有linux驱动API和linux驱动。

准备#

  1. 板子厂商提供的uboot
  2. 一个最小dts
  3. 一个被验证过能用的内核
  4. 一个rootfs

获得uboot#

百度网盘还要注册有点麻烦，去github上找搬运，搜索：正点原子 uboot 然后克隆到本地。实在是没人搬运，只能去下个百度网盘。

关于uboot源码还有linux源码先不管，太硬核，现阶段不要碰，很多linux社区的工程师也未必吃得透整个linux，大部分是专注一个模块。而且也不是闭关修行一个月就能攻破的，他们刚开始也是慢慢精读，花了很长时间。

准备内核和rootfs#

搜索busybox，然后选择自己需要的版本，比如1.29.0或者1.38.0 懒省事可以直接拿zImage还有dtb，rootfs直接用。

busybox天坑，对于GCC14/15#

我比较喜欢用Debian，刚好Debian13出来了，我就用了debian13.

使用menuconfig时，出现找不到ncurses.h，依赖库全装，就是找不到

首先，打开

vim scrips/kconfig/lxdialog/check-lxdialog.sh

然后找到这里

check(){
    $cc -x c - -o $tmp 2>/dev/null <<'EOF'
#include CURSES_LOC
main() {}#旧版本GCC不检查，写的也不规范，新版本直接Warning变error。
EOF
->int main() {}#改成这个

然后

make defconfig
make menuconfig
make install CONFIG_PREFIX=../rootfs

最后就OK了

将uboot写进SD卡的MDR分区#

通过imxdownload工具将uboot.bin写进SD卡。设置SD卡启动。

分区#

sudo fdisk /dev/sdb

o#传统MBR分区
n#new
p#partition
enter#默认则回车键
enter
+256M
t#type
c#W95 FAT32
n#new
p#partition
enter
enter
enter
w#write

#格式化分区

sudo mkfs.vfat -F 32 -n “BOOT” /dev/sdb1

sudo mkfs.ext4 -O ^64bit,^metadata_csum -L "ROOTFS" /dev/sdb2
#debian13特性导致不要64bit和metadata_csum,防止旧版本可能不支持

然后通过MobaXterm控制uboot。

设置网络环境变量#

确保网络通信正常。主机与板子在路由器下或者板子通过网线连到板子上。 先dhcp看到板子的ip

setenv serverip= #主机的ip
setenv ipaddr= #根据主机的ip设置一个
#就这两个就行了

配置tftp#

系统：Debian13

由于Debian13版本引入了严格沙箱和内核级别隔离，所以现在网络服务(TFTP，NFS，FTP)必须放/srv/。

sudo apt update
sudo apt install tftp-hpa tftpd-hpa
sudo apt install xinetd

mkdir /srv/tftp
#这里默认应该就可以了
vim /etc/default/tftpd-hpa
#确认路径是不是/srv/tftp
#其他的建议不动，不用加-l，-c，-s
sudo systemctl restart tftpd-hpa
#不成功的话查看状态
sudo systemctl status tftpd-hpa

将zImage和dtb复制到/srv/tftp,记得查看权限，至少可读

ls -l
sudo chmod +004 zImage
sudo chmod +004 *.dtb

测试#

tftp 80800000 zImage

tftp 83000000 *.dtb

没问题就算搭建成功。

配置nfs#

系统：Debian13

由于Debian13版本引入了严格沙箱和内核级别隔离，所以现在网络服务(TFTP，NFS，FTP)必须放/srv/。

sudo apt install nfs-kernel-server rpcbind
#依然是不建议改路径
sudo vim /etc/exports

/srv/nfs *(rw,sync,no_root_squash,no_subtree_check)
#no_root_squash意思是允许板子以root的身份访问该目录。

debian13 默认不支持NFSv3

sudo vim /etc/nfs.conf
[nfsd]
udp=y
vers3=y
[mountd]
udp=y
vers3=y

重启并查看是否支持v3

sudo systemctl restart nfs-server

cat /proc/fs/nfsd/versions
#显示+3 +4 +4.1 +4.2

在uboot命令行设置

setenv bootargs "console=ttymxc0,115200 root=/dev/nfs nfsroot=192.168.x.xxxx:/srv/nfs/rootfs,v3,udp ip=dhcp rw"
saveenv

然后设置bootcmd

setenv bootcmd "tftp 80800000 zImage; tftp 83000000 *.dtb;bootz 80800000 - 83000000"
saveenv

如果配置正确，boot之后应该能进到到命令行ls能看到主机的/srv/nfs/rootfs下的文件

总结#

整个环境的搭建流程

  1. 准备完整的zImage，uboot，rootfs，dtb。
  2. 烧录uboot
  3. 启动uboot
  4. 配置tftp和nfs
  5. tftp加载zImage和dtb
  6. nfs挂载rootfs
  7. 设置uboot环境变量
  8. boot

其中最容易出错，出错就很折磨的是关于不同的系统，不同的版本下配置tftp和nfs，这个不通的话网络环境就没了。
