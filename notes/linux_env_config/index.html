Linux环境搭建#

如果你很随意的选择内核和工具链，等待你的是折磨最终老实选择还原原厂环境。我就是那一个。

Linux驱动编译的前提#

  1. 拥有板子对应的原厂或者厂商的内核(imx6ull 4.1.15)
  2. 拥有同版本的编译工具链(arm-linux-gnueabihf-gcc 4.9)
  3. 进入内核目录执行脚本(或者自己编译zImage)
  4. 要看到zImage is ready。

Linux驱动编译以及测试#

  1. 然后用这个内核去编译你的驱动程序
  2. 将驱动程序通过网络传到板子上
  3. insmod 然后 rmmod。

Mac环境不适合老旧项目#

在Mac上交叉编译Linux的内核会有哪些问题

  • 老旧项目用的工具链没有Mac平台，有x86_64.
  • Docker Ubuntu环境下, 工具链版本新，还是解决不了⬆️个问题。
